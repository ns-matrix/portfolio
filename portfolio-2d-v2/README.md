# NX-Matrix Portfolio — 2D Version 2

A separate, lightweight 2D portfolio direction for Nitin Singh. This version draws from the dark, terminal-inspired developer aesthetic of the reference portfolio while replacing the 3D canvas with a responsive code-window illustration.

## Preview locally

Open `index.html` directly in a browser, or serve this directory with a local static server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/portfolio-2d-v2/` from the repository root.

## Sections and features

- Responsive 2D hero illustration, rotating role label and accessible mobile navigation.
- Personal profile, contact and external developer links.
- Filterable skills and project cards.
- Experience and education timeline.
- Selected certifications and contact links.
- Reduced-motion support, semantic landmarks and keyboard focus styles.
- No React/WebGL or 3D asset download required; only Google Fonts is external.

## Content notes

Project descriptions are intentionally concise and link back to the existing public GitHub/portfolio surfaces. Review all project URLs and credential details before sharing publicly. Education SGPI note is marked for verification in case new results have been published.

## Deployment

This folder is a standalone static site; set its publish directory to `portfolio-2d-v2` on Netlify (no build command required). The existing root site and production configuration are unchanged by this branch.
